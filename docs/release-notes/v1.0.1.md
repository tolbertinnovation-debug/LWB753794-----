A small update to [LIB Browser 1.0.0](https://github.com/tolbertinnovation-debug/Lib-Web-browser/releases/tag/v1.0.0).

## Fixed

- When a site couldn't be reached, the error page still showed a padlock, as if the page had loaded securely. Error pages now show a neutral info icon, like Chrome.
- After a failed page load, the previous page's reader-mode button stayed in the address bar. It now disappears.

## First launch

These builds aren't signed with a paid code-signing certificate yet, so your system asks for confirmation the first time.

- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **macOS:** if macOS blocks the app, open **System Settings → Privacy & Security** and click **Open Anyway**. If it says the app "is damaged", run `xattr -cr "/Applications/LIB Browser.app"` in Terminal.
- **Linux AppImage:** run `chmod +x LIB-Browser-1.0.1-x86_64.AppImage`, then run the file.
