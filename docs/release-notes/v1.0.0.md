The first release of **LIB Browser**, a fast, private desktop web browser built on Chromium. It comes with ad and tracker blocking, split view, a command palette and reader mode.

## Download

| Your computer | File to download |
| --- | --- |
| **Windows 10/11** (most PCs) | `LIB-Browser-Setup-1.0.0-x64.exe` |
| **Windows on ARM** (e.g. Snapdragon laptops) | `LIB-Browser-Setup-1.0.0-arm64.exe` |
| **Windows, no install** | `LIB-Browser-Portable-1.0.0.exe` |
| **Mac with Apple silicon** (M1 and newer) | `LIB-Browser-1.0.0-arm64.dmg` |
| **Mac with Intel** | `LIB-Browser-1.0.0-x64.dmg` |
| **Linux** (any distribution) | `LIB-Browser-1.0.0-x86_64.AppImage` |
| **Debian / Ubuntu** | `LIB-Browser-1.0.0-amd64.deb` |

The `.zip` files contain the same Mac app as the `.dmg` files. LIB Browser needs Windows 10 or 11, macOS 12 (Monterey) or newer, or 64-bit Linux.

## First launch

These builds aren't signed with a paid code-signing certificate yet, so your system asks for confirmation the first time.

- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **macOS:** drag LIB Browser into Applications and open it. If macOS blocks it, open **System Settings → Privacy & Security** and click **Open Anyway** next to LIB Browser. If macOS says the app "is damaged", run `xattr -cr "/Applications/LIB Browser.app"` in Terminal, then open it again.
- **Linux AppImage:** run `chmod +x LIB-Browser-1.0.0-x86_64.AppImage`, then run the file.
- **Debian / Ubuntu:** run `sudo apt install ./LIB-Browser-1.0.0-amd64.deb`.

To use LIB for links from other apps, open **Settings → General → Make default**.

## What's inside

- **Tabs:** drag to reorder, pin, mute and duplicate them, or tear a tab off into its own window. There are also vertical tabs, split view, and tab sleeping to save memory. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> brings closed tabs back with their history.
- **Smart address bar:** autocomplete from your history, search suggestions and a built-in calculator. Shortcuts like `yt`, `wiki` and `!bang` searches work too.
- **Command palette** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd>): search open tabs, bookmarks, history and every browser action.
- **Privacy:**
  - Built-in ad and tracker blocking (Ghostery engine with EasyList, EasyPrivacy and uBlock Origin lists).
  - Private windows and HTTPS-Only mode.
  - Do Not Track, Global Privacy Control, and optional third-party cookie blocking.
  - Permission prompts that remember your choice for each site.
- **Your stuff:** bookmarks with import and export, history, a downloads manager, reader mode, and a customizable New Tab page. Themes include light, dark and automatic, with accent colors.
- **Reliability:** session restore after restarts and crashes, recovery for crashed tabs, and docked DevTools.

LIB has no accounts, no telemetry and no crash uploads. Your data stays in your profile folder.
